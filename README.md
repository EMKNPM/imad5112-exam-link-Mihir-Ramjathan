
## Objective ##
You have joined a team developing an inventory app for outdoor adventures. The app, "Campsite Commander," needs to store camping gear and food supplies, allow users to categorize them (e.g., Shelter, Cooking, First Aid), and provide a detailed checklist view. Your app must use getting user input, parallel arrays, screen navigation and loops to manage the packing list.

## Splash Screen ##
Display the "Campsite Commander" logo (e.g., a pine tree or campfire) and title while the app is loading.
Transition to the Main Screen after 3 seconds (3000ms).
## Main Screen ##
Display buttons for "Add Gear".
Display the Total Items Packed (calculated using a loop).
Visuals: Use a "Dark Mode" or nature-themed colour palette.
## Detailed View Screen ##
Button to display the full list of gear with details:
Item
Category
Quantity
Specific Notes/Comments
Implement a "Back to Base" button (Navigation) to return to the Main Screen.
## Data Storage ##
Use parallel arrays to store item details, categories, and quantities effectively.
Use appropriate variables and functions needed.
Initialise the arrays with sample data for each.
## Functionality ##
Use a loop to calculate the total number of items.
Ensure the main screen provides easy access to add items and view the list.
Design the detailed view screen to provide additional information for each item.
Include navigation buttons for smooth transitions between screens.
Consider creative ways to present additional item details and packing tips/comments.

## Programming Concepts Used

| Concept | Explanation |
|---|---|
| Kotlin | Used as the main programming language |
| Android Studio | Used as the development environment |
| ConstraintLayout | Used to design the app screens |
| Spinner | Used to allow the user to select a day of the week |
| EditText | Used to capture user input |
| Button | Used to trigger app actions |
| TextView | Used to display headings, average temperature, and weather details |
| Data Class | Used to store information for each day |
| Arrays | Used to store weekly weather objects |
| Loops | Used to calculate averages and display detailed data |
| Functions | Used to organise app logic |

| Intents | Used to navigate between screens |
| ScrollView | Used to allow scrolling on the detailed weather screen |
